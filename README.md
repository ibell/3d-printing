# 3D printing

A collection of my 3D-printed things. Each project lives in its own folder with
its parametric source, print-ready STLs, and notes.

Most designs are parametric OpenSCAD — re-fit them to your own hardware by editing
the parameter block at the top of the `.scad` file and re-exporting, rather than
scaling an STL.

## Projects

| Project | What it is |
|---|---|
| [frame-holder](frame-holder/) | A planar, snap-together desk stand that holds a folding two-photo frame in a lectern posture. Prints flat, no supports, on a 180 × 180 bed. |
